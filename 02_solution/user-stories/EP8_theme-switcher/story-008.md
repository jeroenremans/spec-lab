# S8.8 — Topnav and sidebar fully themed in all 4 themes

**Epic:** EP8 — Theme Switcher  
**Priority:** Must-have

---

**As a** team member using any theme,  
**I want** the topnav and sidebar to be fully themed with no un-styled surfaces,  
**so that** the app looks intentional and coherent in every theme.

**Acceptance intent:** Topnav background, text, search, avatar, theme button all reflect theme tokens. Sidebar background, section headers, tree rows, filter chips, tag badges all themed. No surface falls back to `:root` defaults.

**Dependencies:** S8.1, S8.2.

**Non-goals:** Mobile responsive layout.
