# S8.3 — Theme button in topnav

**Epic:** EP8 — Theme Switcher  
**Priority:** Must-have

---

**As a** team member,  
**I want** a theme icon button permanently visible in the topnav,  
**so that** I can access the theme switcher at any time without navigating away from my current file.

**Acceptance intent:** Theme button visible in topnav right side (before avatar) in all app states. Button has `aria-label`. Clicking opens theme dropdown.

**Dependencies:** S8.1, S8.2.

**Non-goals:** Persistence (S8.6, S8.7); surface audit (S8.8–S8.11).
