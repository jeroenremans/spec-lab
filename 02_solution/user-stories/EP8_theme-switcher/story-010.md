# S8.10 — Modals and tag highlights themed in all 4 themes

**Epic:** EP8 — Theme Switcher  
**Priority:** Must-have

---

**As a** team member,  
**I want** modals and inline tag highlights themed correctly in all 4 themes,  
**so that** modals don't appear as jarring white overlays in dark themes and tag badges remain readable everywhere.

**Acceptance intent:** Project modal and directory browser fully themed. All 5 tag types maintain WCAG AA contrast in all 4 themes. Sidebar AI/YOU recipient badges maintain contrast in all themes.

**Dependencies:** S8.1, S8.2; S8.8.

**Non-goals:** Per-tag custom colours set by user.
