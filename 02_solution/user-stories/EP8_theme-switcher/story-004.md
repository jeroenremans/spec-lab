# S8.4 — Theme dropdown with colour swatches

**Epic:** EP8 — Theme Switcher  
**Priority:** Must-have

---

**As a** team member,  
**I want** the theme picker to show all 4 themes with a colour swatch strip and name,  
**so that** I can visually identify and select the theme I want without guessing.

**Acceptance intent:** Dropdown shows 4 entries, each with theme name + colour swatch strip. Clicking applies immediately and closes dropdown. Clicking outside closes without change. Transition < 100ms.

**Dependencies:** S8.3.

**Non-goals:** Mini full-UI preview; keyboard navigation (v1).
