# S8.5 — Active theme indicator in dropdown

**Epic:** EP8 — Theme Switcher  
**Priority:** Must-have

---

**As a** team member,  
**I want** the currently active theme clearly marked in the dropdown,  
**so that** I always know which theme is active without having to look at the UI and guess.

**Acceptance intent:** Active theme shows checkmark in dropdown. After switching, indicator updates immediately. On first open, Teal Corporate is marked active.

**Dependencies:** S8.4; S8.6 (persistence informs which is active on load).

**Non-goals:** Multiple active themes; custom theme creation.
