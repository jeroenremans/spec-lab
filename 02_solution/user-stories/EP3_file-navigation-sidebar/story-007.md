# S3.7 — Alphabetical sorting of sidebar files and folders

**Epic:** EP3 — File Navigation & Sidebar  
**Priority:** Should-have

---

**As a** team member,  
**I want** files and folders in the sidebar sorted alphabetically by display name,  
**so that** I can predictably locate any file without having to remember the order they were created.

**Acceptance intent:** Files within each folder sorted A–Z by display name (after clean display transform from S3.6). Folders sorted A–Z among other folders. Numbered prefixes (e.g. `01_`, `EP1_`) sort numerically before alphabetically. Sort applies on initial load and after refresh.

**Dependencies:** S3.1; S3.6 (sort by display name, not raw filename).

**Non-goals:** User-configurable sort order; sort by date modified.
